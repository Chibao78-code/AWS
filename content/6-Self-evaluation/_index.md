During my internship with the **First Cloud AI Journey program at Amazon Web Services Viet Nam Company Limited**, from **May 18, 2026** to **August 9, 2026**, I had the opportunity to expand my cloud-computing knowledge and apply concepts from my Software Engineering studies to practical AWS architecture tasks.

My main work included designing an **IoT Weather Platform for Lab Research**, researching and writing three technical articles about modern AWS architectures, and developing the **Secure Hybrid Access to S3 Using VPC Endpoints** workshop. Through these activities, I learned to examine a problem from multiple perspectives, including functional requirements, system architecture, networking, security, scalability, reliability, and cost.

I worked with and researched services and technologies such as **AWS IoT Core, AWS Lambda, Amazon API Gateway, Amazon S3, AWS Glue, AWS Amplify, Amazon Cognito, Amazon EC2, Amazon VPC, AWS PrivateLink, IAM policies, AWS WAF, Amazon CloudFront, and Amazon EKS**. I also improved my ability to read official technical documentation, compare possible solutions, estimate cloud costs, test configurations, organize hands-on instructions, and write technical content in both English and Vietnamese.

Regarding my working attitude, I tried to complete each deliverable responsibly, proactively researched documentation when I encountered unfamiliar topics, and revised my work after identifying inaccuracies or receiving feedback. At the same time, I recognize that I still need more hands-on experience, greater discipline in planning my time, and more confidence when communicating or presenting technical ideas.

### Strengths

* **Independent learning and research:** I can locate and study technical documentation, connect information from multiple sources, and summarize it into a structured solution.
* **Architectural thinking:** I have improved my ability to consider how AWS services work together and to evaluate security, scalability, reliability, and cost instead of viewing each service separately.
* **Responsibility for deliverables:** I made a consistent effort to complete the proposal, blog posts, workshop instructions, and bilingual report with clear explanations and supporting evidence.
* **Willingness to receive feedback:** I am prepared to review my assumptions, correct mistakes, and rewrite content when a better or more accurate approach is identified.
* **Technical documentation:** Researching three architecture topics and building a step-by-step workshop strengthened my ability to present complex information in an organized and understandable form.

### Areas for Improvement

* **Hands-on implementation:** Much of my work focused on research, architecture, and documentation. I need to deploy more complete systems and gain deeper experience in debugging, operations, and handling unexpected failures.
* **Time management and discipline:** I need a more detailed schedule for each milestone so that research, implementation, testing, and documentation are completed evenly instead of being concentrated near a deadline.
* **Communication and presentation:** I should participate more actively in discussions and practice explaining technical decisions concisely and confidently to different audiences.
* **Teamwork experience:** I need more opportunities to collaborate on shared code, perform peer reviews, resolve differences in technical approaches, and coordinate work through a common development process.
* **Depth of problem solving:** I should spend more time validating root causes, testing alternative solutions, and documenting trade-offs before reaching a conclusion.

### Development Plan

* Build a detailed weekly study and implementation schedule with measurable outcomes for each stage.
* Develop a minimum working version of the IoT Weather Platform and manage its infrastructure with Infrastructure as Code.
* Practice CI/CD, automated testing, monitoring, incident troubleshooting, cloud security, and AWS cost optimization through end-to-end projects.
* Participate more actively in technical discussions, peer reviews, and presentations to improve communication and teamwork skills.
* Continue studying AWS architecture and regularly revise existing solutions based on test results, feedback, and newly acquired knowledge.

Overall, this internship helped me build a stronger foundation in AWS and develop a more systematic approach to cloud architecture. More importantly, it helped me recognize both my current abilities and the areas that require further practice. I consider this a valuable starting point for continuing toward a career in cloud computing and software architecture.
